# 数据分析图表选型指南（退款单报告适用）

原则：**按"想表达什么"选图，不一种图打天下；数据完整前提下提高观感，不花哨。**

## 决策表

| 你想表达 | 推荐图 | 何时用 / 何时不用 |
|---|---|---|
| 比较大小（类目间） | 条形 / 柱状 | **偶尔用**。1~2 个分布/排名可用；同类目堆 3 个以上即累赘，改用其它 |
| 看趋势（随时间） | **折线 / 面积** | 周、月、日序列一律用折线，多类目可多线同图 |
| 讲构成（占比） | **饼图 / 环形** | 板块占比、品退 vs 非品退、未发货 vs 发货后 |
| 说分布（区间频数） | **直方图**（柱状变体） | 金额区间、评分分布；本质即分布，可用条形但仅 1 个 |
| 单一数值对比 | **进度条 / 仪表** | 退款率对比（未发货率 vs 发货后率 vs 整体率）一行进度条最直观 |
| 多维综合 | 雷达 | 多指标评分才用，单维别硬上 |

## 本报告的映射（已验证）

| 模块 | 采用 | 弃用 |
|---|---|---|
| 未发货 vs 发货后 | 环形图 + 双进度条 | 纯数字卡片 |
| 四大板块 / 超1000板块归属 / 品退 vs 非品退 | 饼图 | 多条形 |
| 板块周/月趋势、品退周趋势 | 折线 | 堆叠柱 / 柱状 |
| 超1000 金额区间 | 小型条形（分布本质，仅 1 个） | — |
| 高频原因 TOP5、品退原因 TOP5 | 条形（压到 TOP5） | TOP8 全长 |
| 超1000 商品、品退商品 TOP10 | **删除**（第四节已有完整 TOP20 表） | 重复画 |

## 观感红线

1. 条形图数值标签：长条放内部白色字，短条放外部深色字，避免截断。
2. 长标签（商品 ID、原因）自动截断加 `…` + `<title>` 悬停全文。
3. 饼图扇区 < 4% 不标百分比，避免拥挤。
4. 多图并排时统一宽度与单位说明，防止撑破布局。
5. 颜色按板块固定（`COLORS` 字典），跨图一致，降低认知负担。
6. SVG 自绘、不用外部库、不用 CDN，离线打开即看。

## 口诀

> 比大小偶尔条，看趋势必折，讲构成用饼，说分布画方，单一进度上仪表，多维才动雷达。
