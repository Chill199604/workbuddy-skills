# 退款单数据 · 字段映射与口径说明

本文件说明退款单分析 Skill 期望的输入数据结构、字段含义，以及关键统计口径（caliber）决策。
适配对象：淘宝 / 天猫「退款明细」导出的标准字段；其它平台按 `COLUMN_MAP` 别名微调即可。

## 1. 期望输入

- 格式：**xlsx**（单个 Sheet，建议名为 `export`）
- 行：每一行一笔退款单（含「退款关闭」等未成功单）
- 列：至少包含下表「逻辑字段」对应的列

## 2. 字段映射（逻辑字段 → 默认表头）

| 逻辑字段 | 默认表头 | 用途 |
|---|---|---|
| 退款状态 | 退款状态 | 区分 `退款成功` / `退款关闭` |
| 货物状态 | 货物状态 | 未发货 / 未收到货 / 已收到货 / 其它 |
| 售后类型 | 售后类型 | 仅退款 / 退货退款 / 换货 / 补寄 / 维修 |
| 退款总额 | 退款总额 | 退给买家 + 退给平台，整单逆转额（主金额字段） |
| 退给买家金额 | 退给买家金额 | 仅用于明细表展示 |
| 买家退款原因 | 买家退款原因 | 用于品退判定、原因 TOP 分析 |
| 商品id | 商品id | 商品维度排名 |
| 宝贝标题 | 宝贝标题 | 明细表展示 |
| 订单编号 / 退款编号 | 订单编号 / 退款编号 | 明细表定位 |
| 订单付款时间 | 订单付款时间 | 仅展示 |
| 退款完结时间 | 退款完结时间 | **趋势切片的真实时间**（非付款时间） |
| 部分退款/全额退款 | 部分退款/全额退款 | 全额/部分占比 |
| 责任方 | 责任方 | 品退责任判定（如「商家责任」） |

> 字段名不符时，改 `refund_analysis.py` 顶部 `COLUMN_MAP` 右侧的实际表头即可，逻辑名不变。

## 3. 关键口径决策（务必向用户确认）

| 决策点 | 推荐口径 | 说明 |
|---|---|---|
| 退款关闭单 | **排除**，仅单列 | 申请被关闭、钱未退，进退款率分子会虚高 |
| 换货/补寄/维修 | **排除出退款率** | 这类金额通常为 0，属非退款场景 |
| 首要对比 | 未发货 vs 发货后 | 发货后 = 在途仅退 + 已发仅退 + 退货退款 |
| 品退口径 | 广义（商品问题类）或 狭义（仅质量问题） | 广义含 质量/瑕疵/破损/污渍/描述不符/材质/少件/漏发/发错货/缺货/做工 |
| 单品退款率 | 源数据无销售额则只排绝对额 | 要算真实单品退款率需补充各商品销售额 |
| 趋势粒度 | 周 + 月 | 按「退款完结时间」切片，避免历史老订单污染近 90 天窗口 |

## 4. 四大板块判定逻辑

```
未发货退款   = 货物状态 == "未发货"
在途仅退款   = 货物状态 == "未收到货" and 售后类型 == "仅退款"
已发仅退款   = 货物状态 == "已收到货" and 售后类型 == "仅退款"
退货退款     = 售后类型 == "退货退款"
其他(排除)   = 换货 / 补寄 / 维修 等
```

四板块金额相加 == 退款成功总额（校验无遗漏/无重叠）。

## 5. 输出物

- `退款单分析报告.html`：5 大模块（未发货vs发货后 / 四大板块 / 超1000 / TOP商品 / 品退），自绘 SVG 图表，离线可看。
- `退款单明细表.xlsx`：4 个 sheet —— 板块汇总、超1000清单、品退清单、TOP商品明细。
